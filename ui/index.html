System Manual

Quick guide for daily operation and support

How to Use the System

  1. Sign in with your assigned username and password.
  2. Open the Schedule page to review and edit bell times.
  3. Use User Management to add or update staff accounts.
  4. Check Activity Logs for recent system events and alerts.
  5. Run a manual bell test when needed from the control panel.

Frequently Asked Questions

Can I change the bell audio?

Yes. Open the Schedule page and select the bell entry you want to update.

What should I do if the system shows a warning?

Check the Activity Logs and confirm the system status before taking action.
